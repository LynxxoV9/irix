  ### 🗺 Plan d'action Backend par Checkpoints

  • Checkpoint 1 : Socle technique & Structure du projet
      • Structuration des dossiers selon le CDC (agent/, evidence/, mcp/, rag/, llm/, apps/api/, tests/).
      • Définition des dépendances Python 3.12 (requirements.txt) : FastAPI, Pydantic v2, SQLAlchemy, FastMCP, Pytest, HTTPX, etc.
      • Gestion de la configuration (config.py avec pydantic-settings).
      • Mise en place de la suite de tests pytest.
  • Checkpoint 2 : Modèle Logique de Données (MLD) & Persistance PostgreSQL
      • Modélisation SQLAlchemy 2.0 complète selon le CDC (Section 5.2) : User, Investigation, Artifact, ToolExecution, Observation, Hypothesis,
      HypothesisEvidence, Indicator, ThreatIntel, MitreTechnique, HypothesisTechnique, Report.
      • Support SQLite (en mémoire pour tests instantanés) et PostgreSQL (Docker/Production).
      • Schémas Pydantic pour la validation des entrées/sorties.
      • Tests unitaires automatisés des modèles et relations.
  • Checkpoint 3 : Gestion & Ingestion des Preuves (Evidence & Provenance)
      • Endpoints FastAPI de création d'investigation et d'upload d'artefacts.
      • Calcul automatique de l'empreinte cryptographique SHA-256 à l'ingestion, taille et métadonnées.
      • Stockage sécurisé des preuves et traçabilité de provenance (evidence/provenance.py).
      • Tests d'intégration API et validation de l'intégrité des fichiers.
  • Checkpoint 4 : Serveur MCP & Outils Forensiques Spécialisés
      • Serveur FastMCP (mcp/server.py) exposant les premiers outils réels :
          • Hachage et analyse de métadonnées de fichier (mcp/tools/hasher.py).
          • Analyse de journaux EVTX / Windows Events (mcp/tools/evtx.py).
          • Détection de signatures YARA (mcp/tools/yara.py).
          • Enrichissement Threat Intel via Tavily (mcp/tools/tavily.py).
      • Client MCP intégré dans le backend pour invoquer ces outils.
      • Tests unitaires et d'exécution des outils sur des échantillons forensiques.
  • Checkpoint 5 : Boucle Agentique DFIR (PLAN -> DO -> SOLVE -> VERIFY)
      • Connecteur LLM NVIDIA Nemotron via Nebius Token Factory (compatible OpenAI client avec mécanisme de fallback/mock pour les tests hors-
      ligne).
      • Orchestration de la boucle agentique : Planification (planner.py), Exécution via MCP (executor.py), Corrélation et Timeline (solver.py),
      Vérification des hypothèses face aux preuves (verifier.py).
      • Tests agentiques sur un cas de scénario d'intrusion réaliste.
  • Checkpoint 6 : Moteur de Corrélation, MITRE ATT&CK & Génération du Rapport
      • Normalisation des événements et chronologie temporelle (timeline.py).
      • RAG tactique / mapping MITRE ATT&CK.
      • Génération du rapport d'incident complet (Exécutif + Technique + Justifications + Limites) selon l'exigence F11/CA10.
      • Tests de bout en bout du pipeline.
